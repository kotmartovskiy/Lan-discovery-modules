# Lan-discovery-modules

Каталог модулей для панели **LAN Discovery** (вкладка «Модули» → «Каталог»).

## Формат

- `index.json` — индекс каталога: список модулей с `id`, `name`, `description`,
  `type` (`tab` / `block` / `app`), `slot` (для блоков) и `version`.
- `<id>/` — каталог модуля: `module.json` (манифест) и файлы модуля
  (`block.html`, `help.md`, Python-модули и т.д.).

Панель скачивает архив ветки (`codeload.github.com`) и распаковывает каталог
модуля в `modules/<id>/`. Установка, обновление и удаление — только из-под
администратора на вкладке «Модули».

## Как добавить модуль

1. Создайте каталог `<id>/` со своим `module.json`
   (обязательные поля: `id`, `name`, `description`, `type`).
2. Для блока добавьте поле `"block": {"slot": "...", "order": N}`.
3. Добавьте запись в `index.json`.
4. Запушьте в `main`.
5. В панели: «Модули» → «Каталог» → «Обновить каталог».
